# SyscoFlow

Application publiée : https://yachjjnr.github.io/syscoflow/

SyscoFlow convertit une balance générale en états financiers **SYSCOHADA
Révisé (AUDCIF 2017)**, système normal : Bilan, Compte de résultat, Tableau des
flux de trésorerie et Notes annexes.

**Le calcul se fait entièrement dans le navigateur.** Aucune balance, aucun
montant, aucune donnée comptable n'est transmise à un serveur.

Ce dépôt ne contient que le site compilé. Le code source n'est pas public.
